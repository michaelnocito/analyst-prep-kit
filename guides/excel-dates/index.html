The steps

1A date is a numberWhy you can subtract, sort and group dates›

In the standard Windows date system, Excel counts days: January 1, 1900 is day 1, and January 5, 2026 is day 46027. The cell format decides what you see.

FormulaResult
=N(B2)46027
=TEXT(B2,"yyyy-mm-dd")2026-01-05
=B17-B2140

The last line is the gap between the first order (January 5) and the last (May 25). It is plain subtraction.

Change the format and the display changes. The stored number stays the same.

Quick check

You change a date cell from 1/5/2026 to the General format. What do you see?

2Spot text that looks like a dateTest the cell before you trust it›

Put this beside your date column and fill it down:

=ISNUMBER(B2)
ResultMeaning
TRUEA number. If it displays as a date, it is a real date.
FALSEText, blank or an error. Not a date yet.

=N(B2) works too: it shows the number behind a real date and returns 0 for text.

Other clues:

  • The values hug the left edge. Manual alignment can hide this.
  • A PivotTable will not group them by month. Excel may say Cannot group that selection.
  • Sorting puts 10/1/2026 before 2/1/2026, because text sorts character by character.
One working formula proves little. Excel can convert recognizable text on the fly, so =YEAR("19 Jan 2026") returns 2026 and subtracting two text dates can work. Sorting, SUMIFS date ranges, COUNT and PivotTable grouping still treat the cells as text.
Quick check

=YEAR(B2) returns 2026. Is B2 definitely a real date?

3Convert text into real datesThree methods, from quick to precise›

Keep the original column, so you can check the result against it.

1. DATEVALUE

In an empty column, then format the result as a date:

=DATEVALUE(B2)

It reads text using your computer’s date settings, drops any time, and returns #VALUE! for text it cannot read. It also errors on a cell that is already a real date. For a mixed column:

=IF(ISNUMBER(B2), B2, DATEVALUE(B2))

2. Text to Columns (desktop Excel)

  1. Select the text dates.
  2. Data › Text to Columns. Choose Delimited, then Next.
  3. Clear every delimiter box, then Next.
  4. Choose Date and the order the text is written in: MDY, DMY or YMD.
  5. Set Destination to an empty cell, then Finish.
If you leave Destination alone, Text to Columns writes over your original column.

3. DATE with the pieces

For text in a fixed layout such as 2026-01-19:

=DATE(LEFT(B2,4),
      MID(B2,6,2),
      RIGHT(B2,2))

You say which part is the year, month and day. Check the input: DATE rolls extra values forward, so month 13 of 2026 becomes January 2027 with no error.

Quick check

A column reads 25/05/2026 and your computer uses month/day order. In Text to Columns, which order do you choose?

405/01/2026 and two-digit yearsSame text, different dates›

Is 05/01/2026 May 1 or January 5? The text does not say. When Excel reads a CSV or typed text, your regional settings decide.

SettingsExcel reads
US (month/day/year)May 1, 2026
UK (day/month/year)January 5, 2026

If a day/month file is opened with month/day settings, days 1 to 12 can turn into wrong dates, while days 13 and up stay as text. A column with both is a warning sign.

Two-digit years

FormulaResult
=DATEVALUE("1/1/29")January 1, 2029
=DATEVALUE("1/1/30")January 1, 1930

By default, 00 to 29 become 2000 to 2029, and 30 to 99 become 1930 to 1999. A Windows setting can move the cutoff.

Ask the source for yyyy-mm-dd with four-digit years. When you cannot, import with Text to Columns and declare the order.
Quick check

A contract end date arrives as 1/1/30. With default settings, what does Excel store?

5Time hides in the decimalWhy an exact-date match finds nothing›

A whole number is a day. A fraction is part of a day.

Stored numberDate and time
46027.5January 5, 2026 at 12:00
46027.75January 5, 2026 at 18:00

January 5 at 09:14 is about 46027.385. That is not equal to 46027, so an exact lookup for January 5 misses it.

Find a hidden time (above 0 means there is one):

=B2-INT(B2)

Drop the time:

=INT(B2)

Or keep it and count the whole day with a range:

=COUNTIFS(B:B, ">="&DATE(2026,1,5),
          B:B, "<"&DATE(2026,1,6))

For totals over 24 hours, use the format [h]:mm. A value of 1.5 days shows 12:00 as hh:mm and 36:00 as [h]:mm.

6Months, ranges and groupingThe date formulas you reuse›

With B2 holding January 5, 2026 (results shown as yyyy-mm-dd):

FormulaResult
=YEAR(B2)2026
=MONTH(B2)1
=DAY(B2)5
=EOMONTH(B2,0)2026-01-31, month end
=EOMONTH(B2,-1)+12026-01-01, month start
=EDATE(B2,1)2026-02-05, one month later
=B2+302026-02-04, 30 days later
=TEXT(B2,"dddd")Monday
=WEEKDAY(B2,2)1, where Monday is 1
=TEXT(B2,"yyyy-mm")2026-01, a grouping label

A date format code in TEXT depends on Excel’s language. These are English codes. The TEXT result is text: good for labels, not for date ranges.

Total one month

Our orders table has dates in B2:B17 and revenue in H2:H17.

=SUMIFS(H2:H17,
        B2:B17, ">="&DATE(2026,3,1),
        B2:B17, "<"&DATE(2026,4,1))

Result: 2585

“Before April 1” includes March 31 at any time of day. Building the limits with DATE avoids day/month confusion.

7Two Excel odditiesThe fake leap day and the 1904 setting›

February 29, 1900

1900 was not a leap year. Excel treats it as one, for compatibility with Lotus 1-2-3.

=TEXT(60,"yyyy-mm-dd")
=DATE(1900,3,1)-DATE(1900,2,28)
In ExcelResult
Serial 60 as a dateFebruary 29, 1900
Days from February 28 to March 1, 19002

Dates from March 1, 1900 onward are not affected inside Excel. Take care with older dates, or when moving serial numbers to another system. LibreOffice, for example, returns different results for these two formulas.

The 1904 date system

A workbook can count from 1904 instead. The same serial number then shows a date 1,462 days later (four years and one day).

SystemSerial 46027 shows as
1900January 5, 2026
1904January 6, 2030

Switching the setting, or pasting date values between workbooks that differ, can shift dates by that amount with no warning.

Windows: File › Options › Advanced, then under When calculating this workbook, check Use 1904 date system.

The zero comes with no error message. Convert once (step 3), declaring the order of the text.

Other traps

  • Half converted. Compare =COUNT(B2:B17) with =COUNTA(B2:B17). A gap means some filled cells are not numbers.
  • Off by one day. Check whether every row shifted. Look at date systems and time zone conversion in the export.
  • Years merged in a PivotTable. When you group by Months, select Years too.
  • Fiscal year. MONTH follows the calendar. Look dates up in a small table of fiscal periods.
  • Codes turned into dates. Import ID and code columns as Text. Opening the file and fixing it later may not recover the original. See keeping leading zeros. Microsoft 365 also has automatic data conversion settings; they do not cover every date conversion.
