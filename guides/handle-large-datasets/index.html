How to Handle Large Datasets

By Michael Nocito, implementation analyst · Updated November 27, 2026

Excel freezes, or only part of your file loads. Look at the file, move it somewhere built for its size, and bring back a summary.

The steps

1Look before you loadPeek at the top rows and count them›

Check the columns and size before opening the whole file. These commands make a small copy with the first 1,000 lines.

Windows PowerShell

Get-Content big.csv -TotalCount 1000 -Encoding UTF8 |
  Set-Content sample.csv -Encoding UTF8

macOS, Linux, Git Bash

head -n 1000 big.csv > sample.csv

Open sample.csv in a plain text editor. Check:

  • Column names and delimiter
  • Date format
  • Leading zeros on IDs
  • Quoted fields, so a comma inside text does not split a column
  • Odd characters such as Ã©. That is usually UTF-8 read as the wrong encoding.

Now count the lines and write the number down.

Windows PowerShell

$n = 0
Get-Content big.csv -ReadCount 10000 | ForEach-Object { $n += $_.Count }
$n

macOS, Linux, Git Bash

wc -l big.csv
Subtract 1 for the header row. A line count can differ from a record count when a quoted field contains a line break.
Quick check

A file has 3,000,001 lines, including the header. You open it in Excel. About how many data rows are missing?

2Move it into a databaseSQLite with the free DB Browser app›

A spreadsheet has a fixed grid. A database table does not stop at a million rows. New to this? Do Set Up a SQL Database first (about 15 minutes).

  1. Extract the download. Large datasets often arrive zipped with several files. In Windows, right-click the zip and choose Extract All. Our zip held four files and we needed one.
  2. Import the CSV in DB Browser. Tick Column names in first line and name the table recommendations_raw.
  3. Wait. A 2 GB file takes minutes, and the app may look frozen.
  4. Press Ctrl+S to write the changes.
  5. Count the rows and compare with your line count.
SELECT COUNT(*) AS row_count
FROM recommendations_raw;
Check disk space first. The CSV plus the database can total 4 to 6 GB.
3Check the real valuesA filter can return nothing and show no error›

Look at a few rows before you write any filter.

SELECT *
FROM recommendations_raw
LIMIT 10;

In our file, true and false are stored as text. This matches no rows:

WHERE is_recommended = 1

This matches how the data is stored:

WHERE is_recommended = 'true'
Quick check

A filter you expect to match thousands of rows returns zero, with no error. What do you check first?

4Build on a sampleFast testing without waiting on 41 million rows›

Make a smaller table once, then write your query against it.

CREATE TABLE recommendations_sample AS
SELECT *
FROM recommendations_raw
ORDER BY RANDOM()
LIMIT 100000;

Creating a random sample reads the whole table, so the first run takes a while. When your query works, change the table name back to recommendations_raw.

LIMIT is not a sample. Adding LIMIT 1000 to a GROUP BY query limits the result rows. The database still reads the input. Taking only the first rows also follows the file order, which can hide bad data further down.
Quick check

Why can LIMIT 1000 on a GROUP BY query still be slow?

5Summarize, then displayReturn one row per thing you care about›

Showing millions of raw rows can freeze the app. Group them into a summary.

SELECT app_id,
       COUNT(*)   AS review_count,
       AVG(hours) AS avg_hours
FROM recommendations_sample
GROUP BY app_id;

On the full table, this turns 41 million reviews into one row per game. The result is small enough to paste into Excel.

6Index what you search byThe step that speeds up joins and filters›

An index works like the index of a book: the database looks up the value and goes to the matching rows instead of reading through the table.

CREATE INDEX IF NOT EXISTS idx_rec_app_id
ON recommendations_raw (app_id);

On our 41-million-row table this took about 3 minutes, one time. Press Ctrl+S to keep it.

The trap: if your join wraps a column in a function, such as LOWER(title), a plain index on title goes unused. Index the same expression the query uses.

CREATE INDEX IF NOT EXISTS idx_songs_lower
ON artist_songs (LOWER(primary_artist), LOWER(title));

In our case, a join of 13,000 rows to 33,000 rows ran over 30 minutes without this and took seconds with it.

Quick check

Your join uses LOWER(email) on the lookup table. Which index fits?

7Staying in ExcelRow limits, lost rows and the Data Model›

An Excel sheet holds 1,048,576 rows and 16,384 columns. A Google Sheets file holds up to 20 million cells in total.

Did you lose rows?

  1. Press Ctrl+End. Landing on row 1,048,576 is a strong sign the file was cut off.
  2. Compare the sheet row count with your line count from step 1.
  3. Compare the last date or ID in the sheet with the last one in the file.
Excel warns you when it cuts a file off. If someone saves it anyway and shares it, the warning does not travel with the file.

Use Power Query (Excel for Windows)

  1. Data › Get Data › From File › From Text/CSV
  2. Open the arrow beside Load and choose Load To
  3. Choose Only Create Connection and tick Add this data to the Data Model
  4. Build a PivotTable from the Data Model

The rows stay out of the worksheet. Memory still limits the model, especially in 32-bit Excel.

Other limits

LimitValue
Characters in one cell32,767
Digits of number precision15

Format long ID columns as Text before you paste or import. Otherwise a 16-digit number loses its last digit. See leading zeros on CSV import.

8DuckDB and pandasQuery the file without a database import›

DuckDB runs SQL straight on a CSV. Set up DuckDB.

SELECT *
FROM 'big.csv'
USING SAMPLE 1000 ROWS;
SELECT strftime(order_date, '%Y-%m') AS order_month,
       region,
       COUNT(*)    AS order_count,
       SUM(amount) AS revenue
FROM 'big.csv'
GROUP BY 1, 2
ORDER BY 1, 2;

pandas can read a large file in pieces. Load only the columns you need.

import pandas as pd

totals = None
for chunk in pd.read_csv('big.csv', chunksize=500_000,
                         usecols=['region', 'amount']):
    part = chunk.groupby('region')['amount'].sum()
    totals = part if totals is None else totals.add(part, fill_value=0)

print(totals)
