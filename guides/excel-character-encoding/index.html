The steps

1See what happenedBytes read with the wrong codebook›

A text file is stored as numbers called bytes. An encoding is the codebook that turns bytes into letters. A plain CSV usually does not say which codebook it used, so the program has to know or guess.

UTF-8 stores plain English letters in one byte and other characters in two or more. Windows-1252, the old Western European encoding, reads one byte as one character.

Plain digits and unaccented English letters usually survive, so the damage collects in names and punctuation. In my Steam project, 4,685 of 82,956 game names came in damaged, and Excel showed no error. Two reached the top 15 list before I noticed.

The same name spelled two ways is an entity resolution problem.

4Set File Origin at import65001: Unicode (UTF-8)›

These steps are for Excel for Microsoft 365 on Windows. Names can differ in other versions. Opening a CSV directly generally reads UTF-8 correctly when the file has a byte order mark (Microsoft Support). Without one, import it.

  1. Open a blank workbook.
  2. Choose Data, then From Text/CSV, and pick names.csv.
  3. In the preview, set File Origin to 65001: Unicode (UTF-8). It may already be selected.
  4. Check a row with accents. Zoë Brontë should read correctly.
  5. Choose Load. To also set column types, choose Transform Data first.

Importing ZIP codes or IDs too? See keep leading zeros.

6Repair damaged namesRaw file first›

If you have the original file

  1. Import it again with File Origin 65001.
  2. Replace the damaged column, matching rows by an ID, not by position unless you have checked the order.
  3. Refresh your PivotTables and compare row counts before and after.

To save a clean CSV that Excel reads on opening, choose CSV UTF-8 (Comma delimited) as the file type in Save As.

If you only have damaged text

Reversing the wrong reading works for some values and not all. This Python script shows both cases on the practice file.

# Run in the folder that holds names.csv
raw = open("names.csv", "rb").read()

for line in raw.splitlines()[1:]:
    name = line.split(b",", 1)[1]
    right = name.decode("utf-8")
    # Read the same bytes the wrong way
    wrong = name.decode("cp1252", errors="replace")
    try:
        back = wrong.encode("cp1252").decode("utf-8")
    except UnicodeError:
        back = "cannot reverse"
    print(right, "|", wrong, "|", back)
