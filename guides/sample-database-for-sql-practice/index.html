The steps

1See why one table is not enoughJoins need tables that refer to each other›

A single CSV is fine for filters, sorts and totals. To practice joining customers to their invoices, you need at least two tables that share a value.

A sample database holds many tables that are already linked. In Chinook, CustomerId in the Invoice table points to CustomerId in the Customer table. A column used this way is called a key.

Customer tableInvoice table
One row per customer: id, name, countryOne row per sale: id, customer id, date, total
Quick check

What lets a database pair an invoice with the right customer?

2Download ChinookOne file, about 1 MB›

Chinook is a made-up digital music store: artists, tracks, customers, invoices and staff. It comes as a ready-made SQLite file, so there is no server to run and nothing to import.

Download Chinook_Sqlite.sqlite (version 1.4.5) and save it in a folder you can find again, such as Documents.

Skip Chinook_Sqlite.sql on the release page. That is a script that builds the database, and you do not need it today.

SQLite files often end in .sqlite, .sqlite3 or .db. The contents decide whether it opens as a database, not the ending.

You need a program to open the file. Set up a SQL database walks through it.
3Open it and count the rowsCheck that the data arrived with the tables›
  • Open DB Browser for SQLite and choose Open Database.
  • Pick the file. The Database Structure tab should list 11 tables.
  • Go to the Execute SQL tab, paste this query and run it.

Table names alone do not show that the rows came with them. This query counts every table at once. UNION ALL stacks the 11 one-row results into one list.

SELECT 'Album' AS table_name, COUNT(*) AS row_count FROM Album
UNION ALL SELECT 'Artist', COUNT(*) FROM Artist
UNION ALL SELECT 'Customer', COUNT(*) FROM Customer
UNION ALL SELECT 'Employee', COUNT(*) FROM Employee
UNION ALL SELECT 'Genre', COUNT(*) FROM Genre
UNION ALL SELECT 'Invoice', COUNT(*) FROM Invoice
UNION ALL SELECT 'InvoiceLine', COUNT(*) FROM InvoiceLine
UNION ALL SELECT 'MediaType', COUNT(*) FROM MediaType
UNION ALL SELECT 'Playlist', COUNT(*) FROM Playlist
UNION ALL SELECT 'PlaylistTrack', COUNT(*) FROM PlaylistTrack
UNION ALL SELECT 'Track', COUNT(*) FROM Track;

4Run your first joinCustomer names from one table, money from another›

Who are the top five customers by spending? Names are in Customer. Totals are in Invoice.

SELECT c.FirstName,
       c.LastName,
       COUNT(*)               AS invoice_count,
       ROUND(SUM(i.Total), 2) AS revenue
FROM Invoice i
JOIN Customer c ON c.CustomerId = i.CustomerId
GROUP BY c.CustomerId, c.FirstName, c.LastName
ORDER BY revenue DESC, c.LastName
LIMIT 5;

The ON line does the pairing: an invoice row and a customer row belong together when their CustomerId values match. More in SQL JOINs.

5Check the row count after a join412 invoices can turn into 2,240 rows›

InvoiceLine has one row for each track on an invoice. Join it to Invoice and count.

SELECT COUNT(*) AS rows_after_join
FROM Invoice i
JOIN InvoiceLine l ON l.InvoiceId = i.InvoiceId;
412invoices
2,240rows after join
5.4lines per invoice

Each invoice repeats once per line. That is expected. The problem starts when you sum the invoice total across those repeated rows.

SELECT ROUND(SUM(i.Total), 2)                  AS repeated_total,
       ROUND(SUM(l.UnitPrice * l.Quantity), 2) AS line_total
FROM Invoice i
JOIN InvoiceLine l ON l.InvoiceId = i.InvoiceId;
repeated_totalline_total
20848.622328.6
The first number is almost 9 times too high, and no error appears. That is more than the 5.4 average suggests, because invoices with more lines also have larger totals, and they repeat more often. SUM(Total) on Invoice alone returns 2328.6.
Quick check

One invoice totals 10.00 and has 4 lines. What does SUM(i.Total) return for it after the join?

6Find the missing values978 tracks have no composer›
SELECT COUNT(*)                   AS track_count,
       COUNT(Composer)            AS with_composer,
       COUNT(*) - COUNT(Composer) AS missing_composer
FROM Track;
track_countwith_composermissing_composer
35032525978

COUNT(*) counts rows. COUNT(Composer) counts rows where that column has a value. About 28% of tracks have none.

GROUP BY Composer puts them together in one blank (NULL) group. A filter such as WHERE Composer <> 'AC/DC' drops them without any warning. Read NULL in SQL.

Customer has gaps too: of 59 customers, 10 have a company and 30 have a state. A blank state can be normal for an address, so ask what a blank means before you fill it.

Quick check

A column has 100 rows and 20 are NULL. What does COUNT(column) return?

7Join three tablesSales by music genre›

Genre names are two steps away from the sale: InvoiceLine to Track to Genre.

SELECT g.Name                                  AS genre,
       COUNT(DISTINCT l.InvoiceId)             AS invoice_count,
       COUNT(*)                                AS line_count,
       ROUND(SUM(l.UnitPrice * l.Quantity), 2) AS revenue
FROM InvoiceLine l
JOIN Track t ON t.TrackId = l.TrackId
JOIN Genre g ON g.GenreId = t.GenreId
GROUP BY g.GenreId, g.Name
ORDER BY revenue DESC
LIMIT 5;

  • COUNT(DISTINCT l.InvoiceId) counts invoices that include the genre.
  • COUNT(*) counts lines sold.
  • Revenue adds line prices, so an invoice total is never repeated.

One invoice can include several genres, so do not add up the invoice_count column to get total invoices.

Northwind notes

  • These counts are from the file downloaded on November 27, 2026. Other copies of Northwind can be much smaller.
  • Table names are plural, such as Orders. Chinook uses singular names.
  • Order dates run from 2012 to 2023, so views named for 1997, such as Category Sales for 1997, return no rows.
  • One table name contains a space. Put it in double quotes.

Use it on your own data

  • Count rows when you open a database or finish a load.
  • Start with the two tables one question needs.
  • Count rows before and after each join. If the number changes, say why.
  • Write the question as a sentence before you write the SQL.
  • Save queries that worked in a scratch file.
