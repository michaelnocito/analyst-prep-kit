SQL Path · Unit 1

Six words, four typed queries, the same four from memory, the lessons, four questions. About twenty minutes.

Made for a desktop. The queries get long, and a keyboard makes this a lot better.

How this works

One round of SQL, about twenty minutes. Read this once and the rest of it will not surprise you.

The working screen

On the left What to type

The question in plain English, what the answer has to bring back, and the query itself. Later on the query gets covered up and you write it yourself.

On the right Where you type it

A real editor on a real database of 500 songs. Press Run and you get real rows back, not a tick. Every table and column is listed under it.

What happens, in order

    Where you are right now

    Four questions, before anything is taught. Nothing is marked and no answers are shown — this is the map, not a test. You will be asked these same four at the end, and the round will show you what changed.

    Guessing is fine. Not knowing yet is the whole reason the round exists.
