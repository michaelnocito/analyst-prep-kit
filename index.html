Say It Out Loud
For every order, find the matching customer and pull their name alongside the order's revenue.
SELECT o.order_id, c.name, o.revenue
SELECT o.order_id, c.name, o.revenue show the order ID and revenue from orders, plus the name from customers
FROM orders o
FROM orders o pull from the orders table, nicknamed o
JOIN customers c ON o.customer_id = c.id;
JOIN customers c bring in the customers table, nicknamed c
ON o.customer_id = c.id match rows where the order's customer_id equals the customer's id
One-to-many one customer, many orders. That is why customer data lives in its own table.
